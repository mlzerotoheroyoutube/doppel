Doppel

An AI agent that does the work, and a judge that checks every step before anything ships.

Sandeep Vijayarao · github.com/mlzerotoheroyoutube/doppel

The problem

AI agents say “all tests pass.” Sometimes they’re right.

Green tests aren’t proof

An agent can hard-code the answer, weaken a test or skip the hard case, and the CI still passes.

Review doesn’t scale

Reading every AI change by hand defeats the point of the agent. Trusting it blindly ships the mistakes.

What Doppel is

An AI agent framework with a judge built in

Meta Muse: the brain

muse-wonder writes code. muse-spark plans, routes, writes hidden exams and chats.

Fetch.ai: the interface

A uAgent on Agentverse. Talk to it from ASI:One on web or phone. Connects GitHub, calendar and email.

SubQ: the judge

Reads the evidence at every step of the agent loop and decides: ship, or rework.

The agent loop

Evidence first. SubQ decides.

1 · Meta writes

The fix, from the issue

2 · Checks gather facts

Sandbox tests, tamper rules, mutation testing, a hidden exam from the issue alone

3 · SubQ judges

Ship, or rework with its diagnosis

On rework, the agent sees SubQ’s diagnosis, never the hidden tests. Nothing merges without the owner.

Live demo

A cheating PR is blocked. Doppel does the work.

PR #7 · blocked

“Fixes #1. All tests pass.”

The tests were green. The hidden exam, written from the issue alone, failed. SubQ voted don’t ship: the answer was hard-coded.
