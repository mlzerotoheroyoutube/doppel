The problem

AI agents say “all tests pass.” Sometimes they’re right.

Green tests aren’t proof

An agent can hard-code the answer, weaken a test or skip the hard case, and the CI still passes.

Review doesn’t scale

Reading every AI change by hand defeats the point of the agent. Trusting it blindly ships the mistakes.

Agents are good, but “all tests pass” is a claim, not proof. We need a verifier that checks the work, not the agent’s word.
