What Doppel is

An AI agent framework with a judge built in

Meta Muse: the brain

muse-wonder writes code. muse-spark plans, routes, writes hidden exams and chats.

Fetch.ai: the interface

A uAgent on Agentverse. Talk to it from ASI:One on web or phone. Connects GitHub, calendar and email.

SubQ: the judge

Reads the evidence at every step of the agent loop and decides: ship, or rework.

Meta’s Muse models are the brain. Fetch.ai is the user interface, so it works anywhere. SubQ is the judge at every step of the loop.
